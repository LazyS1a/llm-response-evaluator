## Traceability Rules

- Page numbers refer to the PDF page shown by a PDF reader, starting from 1.
- Reference answers and key points are paraphrases, not long source excerpts.
- A human reviewer should check the listed pages before changing a case to
  `human_reviewed`.
- Real model comparisons must store the model name, date, prompt version, and
  raw output separately; the included candidates are synthetic fixtures.
